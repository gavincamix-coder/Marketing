// Platform

Eight primitives. One platform.

Everything you need to authenticate users, authorize access, and audit every action — without stitching together five different vendors.

🔐
Single Sign-On
One login for every app. SAML 2.0, OIDC, and passwordless — configured in minutes, not sprints.
  • 140+ pre-built app connectors
  • Just-in-time user provisioning (SCIM 2.0)
  • IdP-initiated and SP-initiated flows
  • Custom claim & attribute mapping
📱
Multi-Factor Authentication
Step-up authentication that adapts to risk. From SMS to FIDO2, every factor is supported with policy-driven enforcement.
  • FIDO2 / WebAuthn passkeys
  • Authenticator apps (TOTP) & push
  • Biometric on mobile (Face ID, Touch ID)
  • Backup codes & recovery flows
👥
Role-Based Access Control
Model permissions the way your business actually works. Define roles, assign them to users or groups, and let policies do the rest. Supports ABAC and ReBAC for fine-grained scenarios.
  • Unlimited roles, groups, and nested hierarchies
  • Attribute-based policies with CEL expressions
  • Relationship-based access (ReBAC) via graph engine
  • Permission previews & dry-run evaluation
⚙️
User Provisioning
Automate the joiner-mover-leaver lifecycle across every connected system.
  • SCIM 2.0 inbound & outbound
  • HRIS → IdP sync (Workday, BambooHR)
  • Automated deprovisioning
📜
Audit Logs
Every authentication, every policy decision, every admin action — captured and searchable for 7 years.
  • Immutable, cryptographically signed
  • Stream to SIEM (Splunk, Datadog)
  • Retention up to 7 years
🔑
API Authentication
Secure machine-to-machine traffic with short-lived tokens, scoped keys, and per-endpoint policies.
  • OAuth 2.0 client credentials
  • API keys with rotation & scopes
  • mTLS and JWT assertion
🌐
OAuth 2.0 & OpenID Connect
A certified OIDC provider you can trust. Build your own login experience on top of VERIDA's standards-compliant authorization server.
  • OpenID Certified™ (Basic, Implicit, Hybrid, Config)
  • Authorization Code + PKCE, Device, CIBA
  • Custom grant types & token hooks
  • Hosted or embedded login (Headless)
🔄
Directory Synchronization
Keep identities in sync across Active Directory, Entra ID, Google Workspace, LDAP, and any SCIM-compliant source — in real time.
  • AD / Entra / Google / LDAP connectors
  • Delta sync with sub-minute latency
  • Attribute transformation & mapping
  • Conflict resolution & reconciliation
